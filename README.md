# Home Workout

A private calisthenics + Kegel trainer that lives on your phone.

- **Phone app:** add it to the home screen once; it then opens full screen like a normal app and works with no internet
- **Your data stays on your phone:** no account, no server, no laptop needed. One tap saves a backup file to iCloud Drive / Files (or AirDrop it to your laptop)
- Guided workouts: warm-up → exercises with set logging, rest timer and hold timer → cool-down
- Automatic progression: when you max out the reps, it moves you to a harder variation
- Guided Kegel sessions: an animated squeeze/relax circle with sound and vibration cues
- Progress: 12-week calendar, strength charts, body weight, history

See **[PROGRAM.md](PROGRAM.md)** for the training plan. Exercises are defined in `program.js`.

## Install on your phone
1. Open the app's web address in **Safari** (iPhone) or **Chrome** (Android).
2. iPhone: **Share ⎙ → Add to Home Screen**. Android: **⋮ → Install app**.
3. Open it from the home screen icon from now on.

## Backups
Settings → **Save backup** saves a `.json` file. Choose **Save to Files → iCloud Drive** (or AirDrop it to your Mac).
To move to a new phone: install the app there, then Settings → **Restore from backup**.
The app reminds you weekly.
